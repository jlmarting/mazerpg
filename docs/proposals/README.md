# Propuestas del Proyecto

Directorio de propuestas técnicas y mejoras para MazeRPG.

## Convenciones

### Formato de archivo

```
YYYY-MM-DD-titulo-breve.md
```

Ejemplo: `2025-06-07-servidor-dedicado.md`

### Estructura del documento

Cada propuesta debe seguir este template:

```markdown
# [Título descriptivo]

- **Estado**: [Propuesta | En discusión | Aprobada | Implementada | Rechazada]
- **Fecha**: YYYY-MM-DD
- **Fuente**: [rama, issue, discusión, etc.]
- **Dependencias**: [otras propuestas relacionadas]

## Contexto

[¿Qué problema resuelve o qué necesidad satisface?]

## Propuesta

[Descripción técnica de la solución propuesta]

## Consecuencias

- **Positivas**: ...
- **Negativas**: ...
- **Riesgos**: ...

## Alternativas consideradas

[Otras opciones evaluadas y por qué se descartaron]

## Referencias

- Enlaces a código, ramas, issues, etc.
```

### Estados

| Estado | Significado |
|--------|-------------|
| **Propuesta** | Documento creado, pendiente de revisión |
| **En discusión** | Activa, recibe feedback |
| **Aprobada** | Listo para implementar |
| **Implementado** | Ya integrado en `main` |
| **Rechazada** | No se implementará (se mantiene como referencia) |
